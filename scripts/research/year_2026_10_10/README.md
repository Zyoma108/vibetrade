# Исследование 10-11.10.2026: год истории, поиск эджа, трейлинг-выход

Итоги — docs/backtest.md, «Год истории и трейлинг-выход».

ИССЛЕДОВАТЕЛЬСКИЙ код. `rep.py` — векторная копия гейтов детектора и портфеля движка;
на 10.10.2026 совпадает с `engine.simulate` посделочно (243/243, |ΔR| ≤ 1e-15) на четырёх
БД. После любой правки детектора/движка копия устаревает — перед использованием заново
сверить (`cmp_after.py`, `cmp_base` в истории сессии). В боевые решения она не входит.

Окружение: Python 3.11 + numba 0.62 + scikit-learn (numba не собирается под 3.14).
Пути `../dat`, `../hist` — относительно рабочего каталога сессии; поправить под себя.

- `extract.py` — выгрузка свечей/таблиц из БД (immutable) в npz/parquet
- `dl.py` — 3m-свечи Binance USDT-M с data.binance.vision (с долей тейкер-покупок)
- `hist.py`, `regime.py`, `hsave.py`, `hrun.py` — помесячные периоды, восстановленный режим
- `bigsweep.py` + `cfgs.py` + `report.py` — свип по 12 месяцам и 4 БД, парные Δ с bootstrap по суткам
- `search.py`, `ceiling.py` — перебор подмножеств с контролем на перемешанных метках
- `fam.py`, `flush.py`, `hflush.py`, `entry.py`, `short.py` — иные семейства событий и входы
- `run_cfg.py`, `cmp_after.py` — прогон настоящего движка и parity по правилу 3
